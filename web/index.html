关于 Pi Studio

为开发者打造的 AI 编码桌面端

Pi Studio 把 pi coding agent 以 SDK 形式内嵌，在桌面窗口里提供会话浏览、实时对话、模型配置、Skills 管理与项目文件预览。所有数据统一存放在 ~/.pi-studio/，与 pi 命令行数据隔离，互不影响。

无需预装 Node、无需记忆命令行参数 —— 安装即用，让你把注意力放回真正重要的事：写代码。
